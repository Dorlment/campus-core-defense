# 校园核心防线 Campus Core Defense

基于 HTML5 Canvas 的校园科技主题坦克防御小游戏。本项目基于开源坦克大战项目进行二次开发，在原有核心玩法基础上增加了校园数据核心视觉主题、原创 EMP 机制、战绩统计和稳定性修复。

项目保持纯前端、无框架和无需构建的实现方式，适合作为可直接运行和部署的短期 Web 游戏作品。

## 项目特色

- 校园数据核心主题与深蓝紫科技 UI。
- 击毁敌人积累 EMP 能量，每次击毁获得 20 点，最高 100 点。
- 能量达到 100 后按 `K` 释放 EMP。
- EMP 清除当前敌方子弹，并冻结场上敌人约 2 秒。
- Canvas 绘制的轻量 EMP 扩散效果。
- 最终得分、击毁敌人数和有效游戏时间统计。
- 基于最终得分计算的 S / A / B / C 战斗评级。
- 三关基础流程，包含多种敌人、地形与道具。
- 纯静态项目，可通过浏览器和静态文件服务器运行。

## 操作方式

| 按键 | 操作 |
| --- | --- |
| `↑` `↓` `←` `→` | 移动坦克并改变朝向 |
| `Space` / `空格` / `J` | 射击 |
| `K` | 能量满时释放 EMP |
| `P` / `Esc` | 暂停或继续 |
| `Enter` | 菜单确认或开始游戏 |
| `R` | 游戏结束后重新开始 |

击毁敌人可以获得能量。能量达到 100 后，按 `K` 释放 EMP；EMP 会清除当前所有敌方子弹，并冻结场上敌人约 2 秒。玩家自己的子弹不会被清除。

## 技术实现

- HTML5
- CSS3
- 原生 JavaScript
- Canvas 2D
- Web Audio API
- `localStorage`：保存最高分、音频与画质设置、按键映射
- Node.js 内置测试运行器

项目无前端框架、无构建步骤、无第三方运行时依赖。游戏画面、坦克、地形、道具和特效主要通过 Canvas 与 CSS 矢量绘制完成。

## 本地运行

推荐在项目根目录启动静态文件服务器：

```bash
python -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```

也可以使用其他任意静态文件服务器。推荐通过 HTTP 访问，以避免部分浏览器在 `file://` 环境下限制 `localStorage` 或音频能力。

## 二次开发内容

相对于仓库中的原始坦克大战基线，本次二次开发包括：

1. Campus Core Defense / 校园核心防线品牌与校园科技视觉主题。
2. EMP 能量积累、敌弹清除和敌人冻结机制。
3. 击毁敌人数、有效游戏时间和 S / A / B / C 评级统计。
4. 最终得分、击毁数、游戏时间和评级的结算信息展示。
5. Canvas 战场、坦克、地形、数据核心和特效的冷色科技配色。
6. 第三关敌人刷新点被钢墙阻塞的问题修复。
7. Combo 超过时间窗口后未重置的问题修复。
8. 非关卡切换状态可能误触发关卡推进的问题修复。
9. Node.js 24 环境下测试目录参数无法执行的问题修复。

以上改动延续原项目的模块组织和 Canvas 渲染方式，没有更换技术栈或重写核心引擎。
